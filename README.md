# Primitive DB

Консольное приложение на Python — простая база данных с хранением данных в JSON-файлах.

## Возможности

- Создание таблиц
- Просмотр списка таблиц
- Удаление таблиц
- Добавление записей
- Вывод записей в виде таблицы
- Поиск записей по условию
- Изменение записи по ID
- Удаление записи по ID
- Автоматическое создание уникального ID
- Проверка типов данных `str`, `int`, `bool`

## Установка

Для работы проекта необходим Python и менеджер пакетов `uv`.

Установка зависимостей:

```powershell
uv sync
```

## Запуск

```powershell
uv run project
```

## Команды

| Команда | Описание |
|---|---|
| `create_table` | Создать таблицу |
| `list_tables` | Показать все таблицы |
| `drop_table` | Удалить таблицу |
| `insert` | Добавить запись |
| `select` | Показать все записи таблицы |
| `find` | Найти записи по условию |
| `update` | Изменить запись по ID |
| `delete` | Удалить запись по ID |
| `help` | Показать список команд |
| `exit` | Выйти из программы |

## Создание таблицы

После команды `create_table` нужно ввести имя таблицы и поля в формате:

```text
имя:тип
```

Поддерживаемые типы:

- `str` — текст
- `int` — целое число
- `bool` — логическое значение: `true` или `false`

Пример:

```text
create_table
users
name:str age:int active:bool
```

## Добавление записи

После команды `insert` значения вводятся через пробел в формате:

```text
столбец=значение
```

Пример:

```text
insert
users
name=Анна age=20 active=true
```

Поле `ID` создаётся автоматически.

## Поиск

После команды `find` условие вводится в формате:

```text
столбец=значение
```

Примеры:

```text
active=true
age=22
ID=5
```

## Хранение данных

- Структура таблиц хранится в файле `db_meta.json`.
- Записи каждой таблицы хранятся в отдельном JSON-файле, например `users.json`.
